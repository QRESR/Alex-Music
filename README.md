# 🎵 Alex Music

**Приложение для Android** — свой музыкальный сервис с умными подборками
(«Моя волна»), голосовым помощником и **самообучением** под твой вкус.
Состоит из **двух частей**:

1. **Сервер** (этот репозиторий) — ищет музыку, рекомендует и отдаёт звук.
2. **Приложение для Android (APK)** — плеер «Alex Music», который к нему подключается.

Источники: **Яндекс Музыка** и **ВК Музыка** (переключаешь сам). Ассистент
**понимает** запросы («включи 5 треков из сериала…»), но **не выдумывает треки** —
всё берёт из реального поиска.

---

## Что умеет

- 🔍 **Поиск** — текстом, до 10 треков, точный режим, попытки идут **параллельно**.
- 🌊 **Подборки и похожие** — «Моя волна», подбор по **звучанию** (CLAP), а не только по названию.
- 🤖 **Самообучение** — лайки, дизлайки, скипы и дослушивания копятся и
  **меняют выдачу**: нелюбимых артистов и жанры отсеивает, любимые поднимает.
  Чем больше слушаешь — тем точнее подборки.
- 🎙 **Голосовой помощник (LLM)** — понимает естественные запросы, ищет и включает.
- 📱 **Приложение Android** — очередь, плейлисты, дизлайки, переключатель Яндекс/ВК.

## Быстрый старт (пошагово, для новичка)

### Шаг 1. Скачать

```bash
git clone https://github.com/QRESR/music-home.git
cd music-home
```

### Шаг 2. Поставить зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Шаг 3. Ввести СВОИ ключи (каждый — свой!)

Скопируйте шаблон и заполните своими значениями:

```bash
cp private/.env.example private/.env.music-proxy
nano private/.env.music-proxy        # или любым текстовым редактором
```

**Ключи берёт каждый сам** — ничего общего:

| Что | Куда вставить | Где взять |
|---|---|---|
| **LLM** (ассистент) | `private/.env.music-proxy` → `LLM_API_KEY` | свой LLM-провайдер или свой шлюз |
| **Яндекс Музыка** (основной) | файл `private/yandex-token.txt` (одной строкой) | OAuth-токен Яндекс.Музыки |
| **ВК Музыка** (опц.) | файл `private/vk-cookies.txt` | куки своего ВК-аккаунта |

> ⚠️ Папка `private/` **никогда не попадает в git** — ваши ключи в безопасности.
> Без LLM сервер работает (поиск есть), но голосовой помощник выключен.

### Шаг 4. Запустить сервер

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8011
```

Проверьте: откройте в браузере `http://127.0.0.1:8011/health` — должно быть `ok`.

### Шаг 5. Поставить приложение на Android

- Соберите **APK** или установите готовый и укажите ему адрес сервера.
- Готово — ищите, включайте, голосуйте за треки 👍/👎 (это и есть **самообучение**).

## Как это работает

```
Приложение Android (плеер «Alex Music»)
   │   GET /search /radio /stream   ·   POST /smart /radio/feedback
   ▼
Сервер (FastAPI, :8011)
   ├── Яндекс Музыка   ← основной источник
   ├── ВК Музыка       ← отдельный источник (параллельно)
   ├── LLM             ← понимает, что вы просите
   ├── CLAP-эмбеддинги ← подборки по звучанию
   └── feedback.json   ← САМООБУЧЕНИЕ: оценки артистов и жанров
   ▼
Звук на телефон
```

## API (кратко)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/search?q&limit&mix&source` | поиск треков |
| GET | `/radio?id&mode&note` | подборка / похожие |
| POST | `/smart {text}` | голосовая команда → действие |
| POST | `/radio/feedback {id,type}` | лайк / дизлайк / скип → **самообучение** |
| GET | `/stream/{id}` | звуковой поток |
| GET | `/api/taste` `/api/metrics` | вкус / метрики |
| GET | `/health` | проверка, что живо |

## Частые вопросы

**Самообучение — это как?**
Лайк/дизлайк/скип/дослушивание пишутся в `feedback.json` и сразу влияют на
выдачу: артисты и жанры с минусом отсеиваются, плюсовые поднимаются. Пока
правила + накопление истории (не нейросеть) — точность растёт с твоим слушанием.

**Почему нужны свои ключи?**
Это ваш личный сервис: каждый ходит в Яндекс/ВК **со своим** аккаунтом и своим
LLM. Никаких общих/чужих ключей в коде нет.

**Ничего не выдумывается?**
Да. Ассистент формулирует запрос, а треки реально ищутся в Яндекс/ВК.

**Нужен ли YouTube?**
Нет. В текущей сборке YouTube-путь отключён; работают Яндекс и ВК.
